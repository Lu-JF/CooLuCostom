# Changelog

## 0.12.1

- 论文题录与摘要改由 `paper_read` 工具回执提供，内部事件只写编号与处理要求：
  第三方文本不再以 `origin: 'internal'` 进入对话，外部内容按工具数据对待。
- 回执正文加 `<<<外部资料开始/结束>>>` 边界，清洗控制字符，摘要截断到 1200 字。
- 环境提示词补「外部资料的处理」一节：资料里的指令一律不执行，冲突时以提示词为准。

## 0.12.0

- 推送拆成内部通知与外部资料两条事件（0.12.1 起改为工具回执）。

## 0.11.4

- 修复切换推送模式不生效：点开关立即保存，换模式或改最小间隔时重排随机时刻。
- 随机模式的退避改为按最小间隔重排，不再固定等 5 分钟；最小间隔下限放宽到 1 分钟。
- 后台抓取间隔不再暴露给用户，默认每天一次。
- 「arXiv 分类」改名「arXiv 源」，标签并排显示。
- 抓取窗口三个数值等宽左对齐，右侧各加一句说明；配置页提示文本统一精简。

## 0.11.0

- 推送节奏改成两种模式：随机推送（最小间隔 + 每天上限）与定时推送（推送时刻），各自左上角开关切换。
- 取消静默时段、每日上限（定时模式）、气泡轮数上限；轮数固定 4。
- 分区不再使用「新锐期刊」，表外一律「未标注」。
- 推送页的 Token 提示贴近下方卡片。

## 0.10.4

- 期刊集合改为只读：按 ISSN 新增，自动识别刊名与分区，保存时试抓一篇，另有「检测全部期刊」。
- 期刊表取消分组列；arXiv 分类只读；翻译术语表改为只读列表 + 增加词条 + 删除。
- 修正 Structural Health Monitoring 的 ISSN（1477-9217 → 1475-9217）。

## 0.9.3

- 包简介附上项目仓库地址，并补齐 repository / homepage / bugs 字段。

## 0.9.2

- 推送页提示「大肥鱼速评」与「翻译」会消耗 Token。
- Crossref 邮箱旁新增「!」，点开说明该地址的作用与礼貌队列机制。

## 0.9.0

- npm 包名改为 `cortico-world-dailypaper`。
- 配置 → 数据源新增 OpenAlex 密钥输入，密钥写入部署 `.env`，不回显。

## 0.8.4

- 扩展显示名改为「论文推送」。

## 0.8.3

- arXiv 记录带 `journal_ref` 或正式 DOI 时按已见刊处理，列表与推送优先。
- 作者机构改为 OpenAlex 的 `authorships`，查不到机构的条目不收录。
- 修复列表排序被后续排序覆盖的问题；旧条目启动时补 `venue`。

## 0.8.1

- OpenAlex 密钥改从框架秘密存储读取。

## 0.8.0

- 新增「已见刊 / 预印本」徽章与发表信息。

## 0.7.3

- 没有可推条目时给出构成说明；新增「允许推缺摘要」开关，仅对手动推送生效。

## 0.7.0

- 保存配置后立即重排定时器；配置快照防重置；轮数上限进入提示词；静默冲突提示；速评推送前必评并重试。
